# Инструкция: покупка VPS на TimeWeb для сайта BuildX

## Важно понять перед началом

Сейчас у вас на **reg.ru** куплены и домен, и хостинг (тот тарифный план, где сейчас "живёт" сайт). Нужно разделить эти две вещи:

- **Домен (`build-x.pro`) остаётся на reg.ru** — его не нужно никуда переносить, покупать заново или трогать.
- **Хостинг нужно поменять** — вместо хостинга reg.ru сайт будет "жить" на новом сервере (VPS), купленном на **TimeWeb**. reg.ru в этой схеме останется только регистратором домена — то есть просто будет "указывать", куда домен ведёт (на сервер TimeWeb), а сам сайт физически будет работать уже не там.

Тариф хостинга на reg.ru после переезда можно будет отключить/не продлевать — он станет не нужен (но домен продлевать по-прежнему нужно, это отдельная услуга).

## 1. Регистрация / вход
1. Перейти на **timeweb.cloud**
2. Зарегистрироваться (email + телефон) или войти, если аккаунт уже есть

## 2. Заказ сервера
1. В личном кабинете открыть раздел **«Облачные серверы»** (не «Выделенные серверы» — это другое, дороже и нам не нужно)
2. Нажать **«Создать сервер»**
3. Выбрать параметры:

   | Параметр | Значение |
   |---|---|
   | **Локация** | Москва (ближе к аудитории — Московская область) |
   | **Операционная система** | **Ubuntu 22.04 LTS** или **24.04 LTS** (важно выбрать именно Ubuntu, не Windows) |
   | **Конфигурация** | 2 CPU / 4 ГБ RAM / 40–60 ГБ NVMe SSD — этого с запасом хватит для сайта-лендинга с формой заявок |
   | **Тариф оплаты** | Помесячно (можно менять конфигурацию позже без пересоздания сервера) |

4. Нажать **«Заказать»** / **«Создать»**, оплатить

## 3. После создания сервера
TimeWeb пришлёт на почту (и покажет в личном кабинете):
- **IP-адрес сервера**
- **Логин** (обычно `root`)
- **Пароль** (либо сгенерированный, либо тот, что указали при заказе — если предлагали задать SSH-ключ вместо пароля, тоже подходит)

## 4. Что прислать после покупки
Как только сервер создан, пришли мне:
1. **IP-адрес сервера**
2. **Пароль от root** (или доступ по SSH-ключу, если настраивал через ключ)

Дальше я сам всё настрою на сервере: Node.js, PM2, Nginx, SSL-сертификат, задеплою сайт.

## 5. Отдельно — домен на reg.ru
Когда сервер будет готов и я пришлю его IP-адрес обратно (тот же самый, что получишь от TimeWeb), нужно будет:
1. Зайти в личный кабинет **reg.ru**
2. Найти домен `build-x.pro` → **Управление DNS**
3. Добавить **A-запись**: `@` → IP-адрес сервера
4. (опционально) Добавить ещё одну A-запись: `www` → тот же IP-адрес

Это я тоже подскажу пошагово, когда дойдём до этого шага — после того как сервер уже будет куплен и настроен.

---
**Важно:** пароль/доступ от сервера — это чувствительные данные. Присылай их в личном сообщении (не в общий чат с несколькими людьми), и после того как всё настроим — этот пароль стоит сменить на новый, который будешь знать только ты.
